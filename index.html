Findings

What testing caught.

Some of the most useful results were failures. Each one below was caught by a test, fixed, and now has a test that proves the fix.

AccessOpsIdentity

Disabled, but still signed in

Found
After the account was disabled, the person stayed signed in to the app and Keycloak kept their session.
Fixed
Offboarding now ends every Keycloak session and sends a back-channel logout; the step only counts once no session is left.
Proof
22 before-and-after session and token checks, from refresh tokens to a token the app checks itself.

Verification ledger ↗All six gaps →

SignalBridgeAuthorization

Writes accepted after access was removed

Found
A user just removed from a workspace could still complete 4 case writes through a time-of-check to time-of-use gap.
Fixed
The account and role are re-checked inside the database transaction, before the record is locked.
Proof
13 regression tests covering revoked access, disabled accounts and workspace changes.

SignalBridgeDetection

A detection query Splunk refused

Found
pySigma compiled one of my rules into a Splunk query that looked fine, but Splunk refused to run it.
Fixed
I hand-wrote that rule’s SPL with rolling windows and labeled which queries are generated and which are hand-written.
Proof
All five rules run in Splunk Free and a Kusto emulator against the same 48 scenarios.

SignalBridgeIdentity

The security policy blocked sign-in

Found
A keyboard-only browser test showed the console’s Content-Security-Policy blocked the redirect to Keycloak.
Fixed
The console’s policy was corrected and the fix got its own regression test.
Proof
28 Keycloak protocol checks, from callback replay to back-channel logout, and 5 real-browser checks passed.

How I work

I begin with a concrete failure, such as a leaver who can still sign in, an alert that fires twice or an AI report that cites a page it never read, and work back to a control and a test that would catch it. Then I run that test against the real system, keep the record and write down what it doesn’t prove.
