01Identity & access management · Leaver automation

AccessOps

Disabled isn’t done.

When an employee or contractor leaves, a signed HR event ends their access in every system AccessOps can reach and suspends the automated agents they sponsor. Each system is read back to prove it changed, and the rest stays open as owned work until someone else reviews and closes the case.

02Security operations · Detection engineering

SignalBridge

Catch the access that should have ended.

A detection lab that ties each permission change to what an account could actually read. Signed application events feed five versioned detection rules, also written as Sigma with ATT&CK tags, and each finding moves through analyst review to an independently verified fix. It also verifies AccessOps’ leaver events and opens a critical case if a departed account signs in.

Findings

What testing caught.

Some of the most useful results were failures. Each of these was found by a check, fixed, and kept on the record with the test that proves the fix.

SignalBridgeAuthorization

Writes accepted after access was removed

Found
A user just removed from a workspace could still complete 4 case writes through a time-of-check to time-of-use gap.
Fixed
The account and role are re-checked inside the database transaction, before the record is locked.
Proof
13 regression tests covering revoked access, disabled accounts and workspace changes.

SignalBridgeIdentity

The security policy blocked sign-in

Found
A keyboard-only browser walkthrough showed the console’s Content-Security-Policy blocked the redirect to the identity provider.
Fixed
The console’s policy was corrected and the fix got its own regression test.
Proof
28 Keycloak protocol controls, from callback replay to back-channel logout, and 5 real-browser checks passed.

BetTailDatabase security

A NULL slipped past a guard

Found
A database function accepted SQL NULL for a flag, which bypassed its cache-only branch.
Fixed
The function now handles NULL explicitly.
Proof
A regression test proves no request is queued when the flag is NULL.

SignalBridgeLab hardening

A default password in the lab

Found
Scanner triage flagged a default database password, plus containers exposing backend ports with no resource limits.
Fixed
All 8 database role credentials rotated, memory and CPU capped, backend port bindings removed.
Proof
32 credential checks, including rejection of the old default, then a retest of every route and service.

About

Business systems background. Security focus.

I study Management Information Systems at Iowa State, with a minor in Cybersecurity Engineering. I start from how a business process actually runs, like a departure, an alert queue or a shared budget, and build the control that makes it reliable.

How I work

I begin with a concrete failure, such as a leaver who can still sign in or an alert that fires twice, and work back to a control and a test that would catch it. Then I run that test against the real system, keep the record and write down what it doesn’t prove.

I build with AI coding agents under my direction. I set the requirements and threat model, decide what to measure, and review each finding and fix. Each case study states my role, its recorded checks and its limits.
