Selected projects

AccessOps

Local lab · Public demo / Public source

Leaver automation that proves access ended. A signed HR event ends a departing employee’s access across Keycloak, Microsoft Entra ID and a Samba AD-compatible directory and suspends the agents they sponsor; each system is read back, and the case closes only on independent review. Live runs found six gaps that disabling an account leaves open, including a surviving group membership, a token an app kept accepting for two minutes and Kerberos tickets valid for 10 hours; each was fixed or is stated on the case. Access contained 2.6 s after the HR event; the Entra account disabled, removed from its group and its sessions revoked through Microsoft Graph in 20 s (free test tenant); sign-ins after departure reach SignalBridge in 32 s. Operator MFA, OPA policy and a leaked-key drill. Signed v0.4.0 release (401 CI cases). GitHub and Microsoft 365 remain offline fixtures.

Python / Django / PostgreSQL / React / Keycloak / Microsoft Entra ID / OPA

SignalBridge

Local lab / Public source

Access-assurance and detection lab: signed application telemetry, five versioned detection rules (also written as Sigma, with SPL and KQL versions run in a local Splunk Free instance and Microsoft’s Kusto emulator) and an analyst console that takes a finding to an independently verified fix. Live runs against real Keycloak (password and TOTP), Wazuh (8/8 alerts raised exactly once), OWASP ZAP, Shuffle and PostgreSQL (14/14 concurrency and crash-recovery checks). It verifies AccessOps’ signed leaver events and opens a critical case when a departed account is used. A 48-scenario evaluation keeps its misses: precision 15/21 and recall 15/23, on scenarios written with knowledge of the rules. Synthetic data; the full 24-hour run was not completed.
