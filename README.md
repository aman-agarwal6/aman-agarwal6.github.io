## Preview

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173/. Plain HTML, CSS and one deferred local JavaScript file; no framework, build step, package install, trackers, external fonts or third-party assets. The CSP starts with `default-src 'none'` and allows scripts only from this site. There is no runtime data fetch, model call, telemetry collection or browser storage.
