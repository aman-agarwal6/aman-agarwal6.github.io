# Aman Agarwal

Personal portfolio of Aman Agarwal: security engineering, AI systems and information systems projects.

Live site: https://aman-agarwal6.github.io/

- Plain HTML and CSS: no build step, frameworks, trackers or third-party requests.
- Every page sets a strict Content-Security-Policy (`default-src 'none'`), so no scripts run.
- Screenshots show only public pages or clearly labeled fictional sample data.

Preview locally from this folder with `python -m http.server 4173 --bind 127.0.0.1`.
